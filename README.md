# Uneven Ground: Beyond the Barrier
## What is Uneven Ground: Beyond the Barrier?


Uneven Ground: Beyond the Barrier is an immersive virtual reality experience developed for the CAVE2<sup>TM</sup>  environment using the Unity game engine that addresses the UN Sustainable Development Goal 10, which aims to reduce inequalities within and among countries. This project guides users through a high school graduation setting, before transitioning them into the Dark Void, where the user’s anxieties and worries take shape, representing emotional experiences and financial hardships faced by college students. Within the Dark Void, the user encounters 3 interactions within their university registrar office, college cafeteria, and campus bookstore, each designed to highlight the systematic barriers of tuition costs, food insecurity, and access to school materials using ambient sounds, typography, and engaging interactions throughout each building. The experience was exhibited in CAVE2<sup>TM</sup> at the University of Illinois - Chicago, showcasing virtual reality’s potential to immerse users in and contextualize inequalities in higher education.

 This project was developed using the [omicron-unity CAVE2<sup>TM</sup> package](https://github.com/uic-evl/omicron-unity) within Unity version - 2019.2.11.
